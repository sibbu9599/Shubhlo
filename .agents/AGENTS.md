# Celebrato Project Guidelines & Rules

- **Proactive Quality & Bug Auditing**: Automatically inspect, detect, and fix any hardcoded mock data, fallback glitches, UI layout inconsistencies, or data desynchronization issues across all routes and HTML templates without waiting for explicit bug reports.
- **Data Integrity Guarantee**: Ensure all Customer and Vendor dashboards, booking flows, OTP verifications, and ratings reflect authentic database states with zero fake pre-populated records for new users.
- **Premium Responsive Design**: Maintain rich aesthetics, proper grid layouts (e.g. 4-column service catalog grid), compact non-overlapping badges, and clean responsive behavior across all viewport sizes.
